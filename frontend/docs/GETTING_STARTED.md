# Beginner walkthrough

## 1. Open the project

Open the `debugagent-frontend` folder in VS Code.

## 2. Install the dependencies

Open the VS Code terminal and run:

```bash
npm install
```

## 3. Start the website

```bash
npm run dev
```

Open the localhost address Vite prints, normally `http://localhost:5173`.

## 4. First files to edit

### Change project names

Open:

```text
src/data/projects.ts
```

### Change issues

Open:

```text
src/data/issues.ts
```

### Change the dashboard layout

Open:

```text
src/pages/DashboardPage.tsx
```

### Change a reusable button/card/badge

Open:

```text
src/components/ui/Button.tsx
src/components/ui/Card.tsx
src/components/ui/Badge.tsx
```

### Change colors and spacing

Open:

```text
src/styles/tokens.css
```

### Change animations and UI behavior

Open:

```text
src/styles/components.css
```

and the relevant component file.
